# Design System Reference

This file is loaded by the slides skill when making color, typography, and layout decisions.

---

## Color Philosophy

> The palette should feel designed for THIS topic. If swapping your colors into a completely different presentation would still "work," you haven't made specific enough choices.

**Rules:**
- **60/30/10 rule** — one dominant color (60%), one supporting tone (30%), one sharp accent (10%)
- **Dark/light sandwich** — dark backgrounds on title + conclusion, light on content slides. Or commit to dark throughout.
- **Never give all colors equal weight** — pick a dominant and commit

## Typography

### Font Pairings by Tone

| Tone | Header Font | Body Font | Character |
|------|------------|-----------|-----------|
| Formal / Academic | Georgia | Calibri | Classic, trustworthy |
| Corporate / Executive | Arial Black | Arial | Authoritative, clean |
| Modern / Startup | Trebuchet MS | Calibri | Friendly, forward |
| Premium / Luxury | Palatino | Garamond | Elegant, refined |
| Bold / Impact | Impact | Arial | High energy, loud |
| Minimal / Design | Calibri | Calibri Light | Clean, airy |
| Tech / Monospace | Consolas | Calibri | Developer, precise |

### Size Scale

| Element | Size | Weight |
|---------|------|--------|
| Slide title | 36–44pt | Bold |
| Section header | 20–24pt | Bold |
| Body text | 14–16pt | Regular |
| Captions / labels | 10–12pt | Light or muted color |
| Large stat callouts | 60–72pt | Bold |
| Chart labels | 10–11pt | Regular |

### Rules
- Left-align body text and lists; center only titles
- Don't mix more than 2 font families
- Minimum 1.15 line spacing for body text

## Layout Patterns

Use these patterns as a toolkit. Vary layouts across slides — never repeat the same template more than twice in a row.

### Title Slide
- Full-bleed background (dark color or generated image with overlay)
- Large centered title (44–54pt)
- Subtitle / tagline below (18–22pt, muted color or white at 80% opacity)
- Optional: thin horizontal rule between title and subtitle
- NO bullet points, NO body text

### Agenda / Overview Slide
- 3–5 icon + label blocks arranged in a row or 2-column grid
- Each block: small icon (or numbered circle), bold section name, 1-line description
- Clean white or very light background

### Two-Column Content Slide
- Left (55%): Heading + bullet points or paragraph text
- Right (45%): Generated image, chart, or bold stat
- Strong vertical separation (margin or thin divider line)

### Stat / Callout Slide
- 2–4 large stat blocks arranged as cards
- Each card: huge number (60–72pt), small label below (12–14pt)
- Cards have subtle background fill or border radius effect
- Use for data-heavy "impact" slides

### Full-Bleed Image Slide
- Image fills 60–70% of slide width or entire background
- Content in a semi-transparent overlay box or clean sidebar
- Best for section openers or emotionally resonant slides

### Icon Row Slide
- 3–5 icons in colored circles, arranged horizontally
- Bold header below each icon
- 2-3 sentence description below each header
- Use for feature lists, process steps, or comparison of options

### Timeline / Process Slide
- Horizontal arrow or dotted line across the middle
- Numbered nodes along the line
- Label + description above/below each node
- Use for history, roadmaps, step-by-step processes

### Quote Slide
- Large quotation mark graphic (decorative, in accent color)
- Quote text at 22–28pt, italic, centered
- Attribution below at 14pt, muted
- Dark background for visual weight

### Conclusion / CTA Slide
- Mirror the title slide in tone (dark, bold)
- 1–2 sentences summarizing the key takeaway
- Clear call-to-action (if applicable): bold, centered, large
- Contact info or next steps if relevant

## Visual Motif System

Pick ONE motif and apply it consistently across all slides:

| Motif | How it looks | Good for |
|-------|-------------|---------|
| **Colored circles** | Icons sit inside solid colored circles; stats in rounded pill shapes | Friendly, modern |
| **Thick left border** | Every content box has a 6–8pt left border in accent color | Corporate, structured |
| **Corner accent** | Small filled triangle or L-bracket in top-left or bottom-right | Premium, editorial |
| **Card system** | Content lives inside slightly elevated white cards with subtle shadow | Clean, app-like |
| **Diagonal slice** | Background split diagonally between dark and light | Dynamic, startup |
| **Grid overlay** | Subtle grid lines in background (very low opacity) | Tech, data-heavy |

## Anti-AI-Slop Checklist

Before finalizing any slide, verify:

- [ ] **No accent lines under titles** — hallmark of AI-generated slides; banned
- [ ] **No full-width colored header/footer bars** — unless user explicitly asked
- [ ] **No default cream/beige backgrounds** — use white or the user's palette
- [ ] **No text-only slides** — every slide has at least one visual element
- [ ] **No repeated identical layouts** — minimum 3 different layout patterns in a deck
- [ ] **No equal-weight colors** — one color dominates; others support
- [ ] **No hallucinated data** — every stat traces back to user input or certain knowledge
- [ ] **No lorem ipsum or TODO text** — zero placeholders in final output
- [ ] **No light text on light background** — minimum AA contrast ratio
- [ ] **No dark icons on dark backgrounds** — use contrasting circle or light icon
- [ ] **No text overflow** — every text box must contain its content; resize or split if needed
- [ ] **No stacked elements** — check that shapes don't overlap text

## Spacing Standards

- Slide margin (all sides): minimum 0.5"
- Between content blocks: 0.3–0.5"
- Between icon and label: 0.15–0.2"
- Card internal padding: 0.2–0.3"
- Title to first content element: 0.4–0.6"

Leave breathing room. Empty space is a design choice, not wasted space.
